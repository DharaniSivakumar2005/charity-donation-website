# HopeCare – Charity Donation Website

Frontend-only React + CSS project (no backend, no real payment).

## Pages / sections
- Home – charity intro + Donate Now button
- About – short organization description
- Causes – Food, Education, Medical
- Donate – amount select (or custom), cause, donor name + email, validation
- Success message – "Thank you for your donation!"
- Contact – address, phone, email, message form
- Mobile responsive (hamburger menu, stacked cards)

## Run
```bash
npm install
npm run dev
```
Open the URL shown (usually http://localhost:5173).

## Build
```bash
npm run build
```
